## 1. 概述

```bash
mkvinfo [选项] {源文件名}
```

## 2. 描述

此程序列出 Matroska™ 文件中包含的所有元素。输出可以限制为文件中的轨道列表，包括有关所用编解码器的信息。

### 选项说明

| 选项 | 描述 |
|------|------|
| `-a, --all` | 默认情况下，mkvinfo(1) 在遇到第一个集群时停止。此外，它不显示某些经常出现的元素。使用此选项，mkvinfo(1) 将继续处理，无论详细程度级别如何，并显示所有元素 |
| `-c, --checksums` | 计算并显示每帧的 Adler-32 校验和。仅用于调试 |
| `-o, --continue` | 默认情况下，mkvinfo(1) 在遇到第一个集群时停止。使用此选项，mkvinfo(1) 将继续处理，无论详细程度级别如何 |
| `-p, --hex-positions` | 以十六进制显示所有元素的位置，无论详细程度级别如何 |
| `-P, --positions` | 以十进制显示所有元素的位置，无论详细程度级别如何 |
| `-s, --summary` | 仅显示 mkvinfo(1) 找到的内容的简洁摘要，而不是每个元素 |
| `-t, --track-info` | 在详细模式下显示每个轨道的统计信息。如果之前处于级别 0，还将详细程度设置为 1 |
| `-x, --hexdump` | 将每帧的前 16 字节显示为十六进制转储 |
| `-X, --full-hexdump` | 将每帧的所有字节显示为十六进制转储 |
| `-z, --size` | 显示包括头部在内的每个元素的大小 |
| `--command-line-charset 字符集` | 设置从命令行转换字符串的字符集。默认为系统当前区域设置给定的字符集 |
| `--output-charset 字符集` | 设置要输出字符串的字符集。默认为系统当前区域设置给定的字符集 |
| `-r, --redirect-output 文件名` | 将所有消息写入文件文件名，而不是控制台 |
| `--no-bom` | 通常，以 UTF 变体之一创建和编码的文本文件将以字节顺序标记（BOM）开头。使用此选项可禁用写入该字节顺序标记 |
| `--ui-language 代码` | 强制使用语言代码的翻译（例如，德语翻译使用 'de_DE'） |
| `--abort-on-warnings` | 告诉程序在发出第一个警告后中止。程序的退出代码将为 1 |
| `--debug 主题` | 为特定功能启用调试。此选项仅对开发人员有用 |
| `--engage 功能` | 启用实验性功能。可以使用 `mkvinfo --engage list` 请求可用功能列表 |
| `--gui-mode` | 启用 GUI 模式。在此模式下，可能输出特殊格式的行，可以告诉控制 GUI 正在发生什么 |
| `-v, --verbose` | 更详细。请参阅关于详细程度级别的部分，了解将在哪个级别输出哪些信息 |
| `-h, --help` | 显示使用信息并退出 |
| `-V, --version` | 显示版本信息并退出 |
| `@options-file.json` | 从文件 options-file 读取其他命令行参数 |

## 3. 详细程度级别

可以使用 `-v` 选项增加 mkvinfo(1) 的详细程度级别，并打印有关当前文件的更多信息。

### 级别 0

mkvinfo(1) 将仅打印它找到的轨道头及其类型。mkvinfo(1) 将在头完全解析后立即退出（更技术性：在遇到第一个集群时）。在此级别，搜索头条目和提示将不会显示——即使它们位于轨道信息之前。

### 级别 1

mkvinfo(1) 还将打印完整文件遇到的所有 Matroska™ 元素，但不包括搜索头条目和提示条目。如果启用了摘要模式，则 mkvinfo(1) 还将输出帧位置。
可以使用 `--continue` 选项实现相同的效果。

### 级别 2

mkvinfo(1) 还将打印搜索头条目、提示条目以及每个 Matroska™ 元素所在的文件位置。
可以使用 `--all --positions` 选项实现相同的效果。

### 级别 3 及以上

mkvinfo(1) 将打印一些不直接连接到 Matroska™ 元素的信息。所有其他元素仅打印关于刚找到的元素的信息。级别 3 添加元信息以简化调试（请注意：仅适用于开发人员）。级别 3 编写的所有行都用方括号括起来，以便轻松过滤掉它们。

## 5. 退出代码

mkvinfo(1) 以以下三种退出代码之一退出：
| 退出代码 | 含义 |
|---------|------|
| **0** | 此退出代码表示运行已成功完成 |
| **1** | 在这种情况下，mkvinfo(1) 已输出至少一个警告，但运行确实继续了。警告以文本 'Warning:' 为前缀 |
| **2** | 发生错误时使用此退出代码。mkvinfo(1) 在输出错误消息后立即中止。错误消息范围从错误的命令行参数到读/写错误或损坏的文件 |

## 6. 环境变量

mkvinfo(1) 使用确定系统区域设置的默认变量（例如 LANG 和 LC_* 系列）。

### 附加变量

| 变量 | 描述 |
|------|------|
| `MKVINFO_DEBUG, MKVTOOLNIX_DEBUG` 及其简短形式 `MTX_DEBUG` | 内容被视为已通过 `--debug` 选项传递 |
| `MKVINFO_ENGAGE, MKVTOOLNIX_ENGAGE` 及其简短形式 `MTX_ENGAGE` | 内容被视为已通过 `--engage` 选项传递 |

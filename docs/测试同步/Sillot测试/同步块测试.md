# 同步块测试

本文档覆盖所有同步块语法的测试场景。

## 插件级行内同步

这是行内同步测试：`sync-global:test-inline`，后面还有 `sync-global:test-inline-2`。

## 插件级代码块同步

```sync-global
test-codeblock
这是插件级代码块同步的测试内容。

- 列表项 1
- 列表项 2

**加粗文本** 和 *斜体文本*
```

第二个代码块：

```sync-global
test-codeblock-2
另一个插件级代码块同步内容。
```

## 文档级行内同步

文档级行内同步：`sync:doc-inline-1 Lv=20260420 120000{文档行内内容}`

空内容的行内同步：`sync:doc-inline-empty Lv=20260420 120000{}`

多个行内同步：`sync:doc-multi-a{内容A}` 和 `sync:doc-multi-b{内容B}`

## 文档级代码块同步

```sync-block
doc-codeblock-1 Lv=20260420 120000
这是文档级代码块同步的测试内容。

> 引用文本
> 第二行引用
```

空内容的文档级代码块：

```sync-block
doc-codeblock-empty Lv=20260420 120000
```

## 混合场景

一段文字中同时包含 `sync-global:mixed-test` 插件级行内和 `sync:doc-mixed{文档级行内}` 文档级行内同步。

以及下方的插件级代码块：

```sync-global
mixed-codeblock
混合场景下的插件级代码块内容
```

和文档级代码块：

```sync-block
doc-mixed-block Lv=20260420 120000
混合场景下的文档级代码块内容
```
